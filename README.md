# Password-Based LED Control Using Arduino Uno

## About the Project
This project uses an Arduino Uno and a keypad to control an LED using a password.

## Components Required
- Arduino Uno
- Keypad
- LED
- Breadboard
- Jumper wires

## Working
Enter the password using the keypad to control the LED.
